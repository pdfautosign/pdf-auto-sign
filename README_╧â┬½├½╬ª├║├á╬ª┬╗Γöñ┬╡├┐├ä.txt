PDF Auto Sign V1.4.6 — Android PWA 安装版

这不是 APK，而是可安装到 Android 主屏幕的 PWA。

部署：
1. 将 ZIP 上传到 Netlify Deploy（或其他支持 HTTPS 的静态网站服务）。
2. 部署完成后，在 Android 手机 Chrome 中打开网站地址。
3. 点 Chrome 菜单「⋮」→「添加到主屏幕」或「安装应用」。
4. 确认后从手机主屏幕启动。

本版本沿用用户确认可用的 V1.4.6 PDF 签名程序；添加 Android 安装说明页面和应用标识设置。

注意：
- 不要把 ZIP 直接当 APK 安装。
- PDF 库与字体通过外部 CDN 加载，部分功能需联网。
- 本机资料保存在浏览器内，换设备不会自动同步。请使用应用内备份。
- 如果已有旧版本安装，请先确认个人资料已备份，再更新。
